# CHANGELOG

本文件记录 TeachMeChat（交我聊）的主要变更。版本号与 `teachmechat/__init__.py` 中的 `__version__` 保持一致（桌面“关于”对话框自动引用该值）。

## 0.2.0（2026-10-09）

首个桌面预览版，从终端原型扩展为完整的 Windows 桌面应用。

### 新增

- **桌面三栏界面**：联系人 / 聊天记录 / 建议三栏布局，回复卡片可一键复制（仅点击时修改剪贴板）。
- **圆角无边框窗口**：圆角外框与同色自定义标题栏，保留最小化、最大化/还原、关闭、拖动与边缘缩放。
- **状态机器人**：底部黑色液晶状态屏（亮绿像素字 + 扫描线，字号整体放大），红绿灯位于屏幕内部；分阶段表情（`@@` 未连接 / 平静读取 / 微笑完成）与生成红灯、完成绿灯。
- **自动刷新**：5 秒自动刷新开关与环形箭头手动刷新按钮；无新消息不重复调用模型。
- **上下文条数**：100 / 200 / 500 / 1000 条快捷选项与自定义 1–5000 条，实际用于数据库读取并跟随保存模式记忆。
- **模型目录**：按各厂商 2026-10 官方文档逐型号登记推理档位（精确模型 ID + 协议，共 49 条），内置来源链接与证据等级；未知模型只提供 default。
- **供应商模板**：OpenAI、Google Gemini、DeepSeek、GLM、Anthropic、Kimi，自定义兼容接口。
- **DPAPI 加密保存**：API Key 与配置绑定当前 Windows 用户加密保存，支持“加密保存 / 仅公开配置 / 仅本次会话”三种模式。
- **只读 SQLCipher 实时读取**：读取微信 3.x / 4.x 数据库快照与运行中数据，只读不写入源库。
- **图片与语音处理**：图片本地解码剥除元数据后交视觉模型；语音优先本地 Whisper 转写，缺少后端时明确回退不冒充。
- **可移植运行目录**：默认项目内 `.teachmechat-runtime`（任意本机绝对路径），可选 `TEACHMECHAT_REQUIRE_DRIVE` 强制盘符。

### 安全与发布

- 发布审计：`release.py` 显式源码允许清单 + SHA256 manifest；源码包不含运行时、数据库、密钥或模型。
- 安全加固：密钥不落盘、不打印；只读路径校验；外部请求需用户逐项确认。
- 开源社区文件：NOTICE、CONTRIBUTING、SECURITY、PUBLISHING、WECHAT_COMPAT、PROMO 与 GitHub Actions 测试工作流。

## 0.1.0

- 首个终端原型：本地读取微信数据，调用用户自配模型生成回复建议，验证“只生成草稿、不自动发送”的核心流程。
