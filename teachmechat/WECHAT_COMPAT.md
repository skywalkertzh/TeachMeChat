# 微信版本适配说明（WECHAT_COMPAT）

本文说明 TeachMeChat（交我聊）自动读取微信本地数据的支持范围、连接流程、常见问题、安全边界与未验证项。**真实兼容矩阵尚未对所有微信 3.x / 4.x 构建版本做全面验证**：合成数据库测试通过不代表你的微信版本一定可用；文中结论需真机验证，以你实际“获取到的状态”为准。

自动读取的对象是**你本机已登录账号的数据库**，使用 SQLCipher 只读连接：不写入源库、不强制 checkpoint、不在活动库上使用 immutable。读取需要微信保持登录；先启动应用、后启动微信也可以（应用会等待）。

## 支持范围

| 微信版本 | 进程与读取组件 | 成功条件（设计要求，非兼容性保证） | 失败时的提示 | 替代方案 |
|---|---|---|---|---|
| 3.x | `WeChat.exe`；`wxManager/decrypt/wx_info_v3` + `version_list.json` 静态偏移表；SQLCipher 3 | 微信已登录；安装版本在静态偏移表内；当前只有一个微信进程；当前用户可只读打开进程；取钥并通过校验 | 版本不在表中 → 405：“当前微信版本不在仓库支持表中，请选择手动配置或快照模式。” | 手动填写数据库目录 + 密钥（不保存）；明文快照导入；纯手动录入背景 |
| 4.x | `Weixin.exe`；`wxManager/decrypt/wx_info_v4`；经进程句柄定位数据目录、扫描内存候选密钥并用数据库首页校验；SQLCipher 4 | 微信已登录；数据目录存在（含 `favorite/favorite_fts.db` 或 `head_image/head_image.db`）；当前只有一个微信进程；可只读打开进程；候选密钥通过首页校验 | 尚未登录 / 条件未就绪：“微信尚未登录或仓库尚不能取得此版本的读取条件。” | 同上 |

补充说明：

- 版本按进程名识别：`WeChat.exe` 视为 3.x，`Weixin.exe` 视为 4.x。**自动连接要求当前只有一个微信进程**；检测到多个微信进程时桌面版拒绝自动连接并提示“检测到多个微信进程。请使用手动连接，避免选择错误账号。”旧版 3.x 多开还额外受限：取钥按进程名匹配，无法安全区分多个 3.x 进程，多开场景请用手动目录 + 密钥。
- 读取走 SQLCipher 只读连接（优先 `sqlcipher3`）：`mode=ro`、`query_only`、仅允许 SELECT、单查询有时间预算；检测到 WAL 但缺少 SHM 时会拒绝读取（“请由数据库所属应用恢复 SHM 后重试”），避免创建或改动源文件。
- 缺少 SQLCipher 时明确报错，**不会回退为明文读取或导出数据库**。
- 上表“成功条件”只是必要条件，不是对所有微信构建版本的兼容承诺；每条都需真机验证。

## 连接流程时序

先启动应用、后启动微信也可以（应用会等待）：

1. 启动桌面版，点击“连接微信”，确认仅访问本人有权处理的数据。
2. 微信尚未运行时，应用每 3 秒检测一次进程，界面提示“等待微信启动与登录……”。微信也可以在应用启动之后再启动。
3. 在微信完成登录（例如手机扫码确认）。应用检测到进程后提示“正在验证本地读取条件……”。
4. 获取读取条件：3.x 查静态偏移表并读取账号信息；4.x 打开进程句柄、定位数据目录、扫描候选密钥并用数据库首页校验。等待期间提示“等待微信登录，或当前版本尚未支持。可随时取消连接。”
5. 取得读取条件后列出会话；选择联系人、上下文条数，再生成草稿。密钥仅留在本程序内存，不写日志、不落盘。

时序中的边界：

- 微信需要保持登录。微信退出或重启后，应用停止采集并提示“微信进程已退出或重启；请重新选择在线账号，旧会话不会继续采集。”重新连接即可继续。
- 单次获取读取条件有 90 秒超时；超时后会结束本程序的读取任务，**不会退出微信**。
- 同进程换号（不退出微信直接切换账号）**未被证明能完全检测**；遇到时请断开后重新连接，当前不宣传无缝多账号。

## 常见问题

**Q：需要重新登录微信才能看到新消息吗？**
一般不需要：实时模式在刷新/自动刷新时会按 SQLite 正常方式读取当前数据库（含 WAL 变更）。如果看不到新消息，按顺序排查：

1. 是否在使用“明文快照 / 快照导入”——快照是导出时点的数据，不会变成实时数据，需重新导出或改用在线连接；
2. 是否复用了**旧快照目录**（读到的仍是旧时间点）；
3. 微信是否曾退出或重启（应用会停止采集，需重新连接）；
4. 是否开启了自动刷新（每 5 秒检查）或手动点了刷新。

若来源是离线导出的数据库，导出时未包含 WAL 里的内容不会被补采，这是来源本身的限制，重登微信也不会改变已导出快照的内容。

**Q：提示权限不足？**
应用以当前用户运行、不自动提权。若微信以更高权限级别运行，可能出现无法只读打开进程（提示“无法只读访问微信进程”）。请让两者以相同权限级别运行，或改用手动目录 + 密钥方式。

**Q：提示版本不匹配（405）？**
表示微信安装版本不在 `version_list.json` 静态偏移表内，自动方式会明确拒绝而不是猜测。可选替代：手动目录 + 密钥、明文快照导入、纯手动录入背景。

**Q：获取读取条件超时？**
90 秒内未取到读取条件会提示“获取读取条件超时；已结束本程序读取任务，未退出微信。”确认微信已登录且进程唯一后重试；部分安全软件可能影响进程内存读取，建议如实评估后再继续。

**Q：媒体缺失 / 图片显示占位？**
原图缺失时退回缩略图；不支持的加密或图像格式会明确显示缺失，不编造内容。部分 4.x 图片格式可能不被支持，以实际获取到的状态为准。语音：本地 turbo 转写需自备权重；未配置或失败时只回退到微信已有转写，不冒充 turbo。

## 安全与隐私边界

- **只生成草稿**：不自动发送微信消息、不自动点击、不注入微信进程；复制草稿必须手动点击。
- **只读读取**：不写入源数据库、不强制 checkpoint、不在活动库上使用 immutable；WAL 共享内存/锁文件属于 SQLite 引擎的正常行为，**不能保证源目录字节绝对不变**。
- 读取前需要用户授权；密钥仅存于程序内存，不写日志、不保存；连接、切换会话或更换 API 服务后需重新确认外发范围。
- 聊天内容外发到模型 API 前需用户确认；不自动上传旧上下文，失败也不会悄悄反复上传。
- 不通过隐藏进程、关闭防护或绕过安全软件来规避提示；读取本机微信进程仍可能触发安全软件关注，应透明说明。

## 未验证清单

以下事项尚未被证明，文档与对外文案中不应宣称：

- 所有微信 3.x / 4.x 构建版本的真机兼容矩阵；合成数据库测试通过不代表真机全兼容，需真机验证。
- 同进程微信换号的完整检测能力；当前要求断开重连，不宣传无缝多账号。
- 微信版本更新后静态偏移表（`version_list.json`）的长期有效性；需随上游仓库持续维护。
- 全部 4.x 图片/动图格式；部分格式可能不支持。
- Whisper turbo 的真实性能、显存占用与下载（需用户自备权重，未默认安装）。
- 新机器干净安装、签名、完整第三方许可审核等发布能力（另见 [RELEASE_AUDIT.md](RELEASE_AUDIT.md) 与 [VERIFICATION.md](VERIFICATION.md)）。
