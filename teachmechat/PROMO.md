# PROMO · “交我聊”发布与传播文案

> 文案边界：不承诺“高情商”、恋爱成功率或关系结果；统一强调——**帮你把话说好，发不发、怎么改由你决定。**

## 为什么叫“交我聊”

上海交大校园里，CampusDate 常被同学戏称为“交我配”。我顺着这个梗做了“交我聊”：不是替你聊天，也不是研究什么“话术套路”，而是在你卡壳的时候，先给你三个可以继续改的表达草稿。

它当然可以处理约会、暧昧和对象闹别扭，但不只如此：工作群里怎么回领导、怎样委婉拒绝同事、家人吵架后怎么开口、想回怼又不想撕破脸、很久没联系的人怎么破冰，都属于“想说，但一时不知道怎么说”的时刻。

## 一句话定位

**本地只读的 Windows 微信回复草稿助手：看你授权的聊天上下文，用你自选的模型生成三条回复建议；只出草稿，绝不自动发送。**

项目基于 [LC044/WeChatMsg](https://github.com/LC044/WeChatMsg)（留痕 / MemoTrace，MIT）二次开发。

## 它能做什么

- **约会与破冰**：不知道如何自然接话时，给出几种不油腻的表达起点。
- **哄对象 / 家人**：先组织情绪和重点，再选择更像自己的说法。
- **领导 / 同事**：被临时点名、催进度、要汇报时，生成简洁或更正式的草稿。
- **委婉拒绝**：明确边界，同时尽量不给对方难堪。
- **克制地回怼**：把情绪变成事实、诉求和边界，避免一冲动把局面搞坏。
- **道歉与和解**：帮你迈出最难写的第一句。
- **事务性寒暄**：节日问候、久未联系、活动邀约，先有一版不尴尬的底稿。

这些只是措辞参考，不能保证沟通效果，也不替你判断对方心理。

## 为什么不直接做“自动回复”

因为消息最终代表的是你。TeachMeChat 的边界是：

- 只生成草稿，不自动发送、不自动点击微信；
- 只读取你明确授权、本人有权访问的本机聊天；
- 微信数据库只读，不强制 checkpoint，不写回源库；
- 发送聊天内容到模型 API 前，显示接收方和范围并再次确认；
- API Key 可用 Windows DPAPI 绑定当前用户加密保存，也可以不保存；
- 不监控他人、不“读心”、不做心理诊断。

## 主要功能

- Windows 三栏桌面界面：联系人 / 聊天 / 回复建议；
- 100 / 200 / 500 / 1000 条上下文或自定义 1–5000 条；
- 5 秒自动刷新与手动刷新，新消息从底部推入；
- 三条回复草稿 + 对话分析 + 非诊断性的沟通提醒；
- 图片描述与语音转写（可选本地 Whisper turbo）；
- OpenAI、Google Gemini、DeepSeek、GLM、Anthropic、Kimi 与自定义兼容接口；
- 按精确模型 ID 匹配思考开关 / 推理强度；
- 像素机器人 + 黑底亮绿 LCD 状态屏，生成红灯、完成绿灯；
- 微信 3.x / 4.x 数据结构适配，真实兼容性以本机测试为准。

### B站 / 视频简介

你有没有遇到过这种时刻：消息看懂了，但不知道怎么回；或者想回得体一点，又不想像复制粘贴的 AI 套话？

“交我聊”是一个 Windows 桌面回复草稿助手。它基于 WeChatMsg 的本地微信数据读取能力，在你明确授权后只读查看选中会话的上下文，再调用你自己配置的模型，生成三条不同方向的回复草稿。它可以用于恋爱聊天，也能处理工作群回复、委婉拒绝、克制回怼、道歉和家人沟通。

为了保留人的决定权，它不自动发送、不自动点击微信；图片和语音可以作为上下文，API Key 可以在本机加密保存。视频里会演示：连接微信、选择联系人、控制上下文条数、切换不同模型和思考档位、刷新消息，以及复制一条建议自己修改。

### 公众号 / 长图文开头

很多时候，沟通的难点不是“没有观点”，而是如何把观点说得准确、得体，又保留自己的语气。工作消息要简洁，拒绝要有边界，道歉要真诚，亲密关系里的回复又不能像公文。

TeachMeChat（交我聊）尝试把 AI 放在“发送之前”这一小步：它以只读方式读取用户授权的本机微信会话，结合可选的图片描述与语音转写，生成三条回复草稿和对话分析。用户可以复制、修改，也可以完全不用。软件不自动发送、不自动点击微信，并把外发目标和范围展示给用户确认。

名字借用了交大同学对 CampusDate“交我配”的戏称，但项目并不局限于约会场景。它希望解决的是更普遍的问题：**让人在重要、尴尬或情绪化的时刻，多一个组织语言的机会。**
