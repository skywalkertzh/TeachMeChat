# 视觉方向：雾灰与鼠尾草绿

本轮针对“纯白太亮、纯黑压抑”的反馈，选择中等亮度、低饱和的雾灰表面，以鼠尾草绿区分选中和自己的消息，深绿色只用于主要操作。不是把整个应用降低透明度，也不声称具有医学护眼效果；舒适度仍取决于屏幕亮度和环境光。

## 公开设计参考

本轮定向查阅以下公开资料，不是穷尽全网，也未复制其商标、图标或具体界面：

1. [Microsoft Fluent 2 — Color](https://fluent2.microsoft.design/color)：中性色承载内容结构，语义色表示状态，并配文字/图标。
2. [Microsoft Fluent 2 — Material](https://fluent2.microsoft.design/material)：以材质/层次区分区域；本应用采用实色层级，不引入复杂透明玻璃。
3. [Material 3 ColorScheme 官方实现说明](https://api.flutter.dev/flutter/material/ColorScheme-class.html)：surface/container/onSurface等成对色彩角色；按前景/背景组合检查对比。
4. [Linear UI 重设计复盘](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少多余色偏、统一主题并增强文字/图标对比，而非简单全体变灰。

## 本应用的设计决策（不是参考产品的官方配方）

- 画布 `#B8C2BD`，取代接近白色的旧背景。
- 内容面板 `#D2D9D2`，卡片 `#DCE2D9`，输入区 `#E0E5DD`，通过小幅亮度差建立层级。
- 正文 `#263A32`，辅助文字 `#3F5147`，降低背景亮度但不把文字也调得难以阅读。
- 主按钮 `#355D4B` 与柔和浅色字 `#EDF1E8`。
- 红/绿信号灯保持明确颜色含义；异常、暂停、忙碌仍配文字。
- 窗口、设置表单、菜单、消息卡片与机器人共享语义色常量，避免弹窗/局部控件突然纯白。
- 边框与圆角略收敛，减少“塑料白卡片”观感；交互顺序、数据源、API配置与存储策略不变。

自动测试检查普通正文和辅助文本在主要表面至少4.5:1，排除禁用控件的正常文本要求；它不能替代实际屏幕视觉检查。实际Qt窗口预览仅使用合成消息，不读取用户聊天或模型配置。
